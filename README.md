# تعريب Judgment العربي — المثبّت المستقل

أداة Windows لتثبيت حزمة التعريب. في النسخة المستقلة المبنية محلياً، تكون أداة التثبيت وملفات الحزمة مضمّنة داخل **ملف EXE واحد**؛ لا يحتاج المستخدم إلى اختيار ZIP منفصل أو الاتصال بالإنترنت.

## الحالة الحالية

- إصدار أداة التثبيت: 1.0.0.
- الحزمة المحلية أُعدّت بتاريخ 14 نوفمبر 2026.
- تتضمن الحزمة المحلية: `db.judge.en.par`، وملفي الخط العربي، وملف تعريف التعريب.
- هذا لا يعني اكتمال ترجمة جميع موارد اللعبة؛ لم يتغير `ui.judge.en.par` في النسخة المرصودة، ولم يثبت الفحص ترجمة جميع الموارد الأخرى.

## استخدام النسخة المستقلة

1. احصل على نسخة قانونية من لعبة Judgment وثبّتها.
2. شغّل `Judgment-Arabic-Installer.exe`.
3. اختر مجلد اللعبة، أو المجلد الأب الذي يحتوي على مجلد Judgment.
4. اضغط «تثبيت التعريب».
5. يقرأ المثبّت ملفات التعريب المضمّنة داخله، ويتحقق من بصماتها، وينشئ نسخة احتياطية قبل استبدال الملفات.

**لا يلزم ملف ZIP منفصل** عند استخدام النسخة المستقلة.

للتراجع، شغّل المثبّت مرة أخرى، واختر مجلد اللعبة، ثم اضغط «استعادة آخر نسخة احتياطية».

## البناء من المصدر

يتطلب البناء Windows و.NET Framework 4.x compiler (`csc.exe`) وملف الحزمة الخاص المتوفر محلياً في:

    private-payload\Judgment-Arabic-Patch-2026-11-14.zip

نفّذ:

    powershell -ExecutionPolicy Bypass -File .\build.ps1

سينتج:

    dist\Judgment-Arabic-Installer.exe

يقوم سكربت البناء بضم ملف ZIP كـ Embedded Resource داخل EXE. مجلد `private-payload` مستثنى من Git عمداً؛ لذلك لا يمكن إعادة بناء النسخة المستقلة من المستودع العام وحده من دون توفير ملف الحزمة الخاص محلياً.

## الخصوصية والسلامة

- لا يتصل البرنامج بالإنترنت ولا يرسل ملفات اللعبة.
- يتحقق من أسماء الملفات وبصمات SHA-256 قبل الكتابة.
- يرفض المسارات غير المسموح بها داخل الحزمة المضمّنة.
- ينشئ نسخة احتياطية للملفات الموجودة قبل استبدالها.
- يتطلب إغلاق اللعبة قبل التثبيت أو الاستعادة.

## إخلاء المسؤولية والتوزيع

هذه أداة مجتمعية غير رسمية، وليست تابعة إلى SEGA أو Ryu Ga Gotoku Studio. Judgment وعلاماتها وملفات اللعبة الأصلية ملك لأصحاب الحقوق. يحتوي هذا المستودع العام على كود المثبّت والوثائق فقط، ولا يحتوي على حزمة التعريب أو موارد اللعبة. ملف EXE المبني محلياً يضم موارد معدّلة مشتقة من ملفات اللعبة؛ لا توزّعه علناً إلا إذا كنت تملك حقوق التوزيع أو إذناً من صاحب الحقوق.
